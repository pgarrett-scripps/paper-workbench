# Claim reconciliation development retest

This retest reuses the Dobson Drosophila manuscript from the previous trial. The engineering changes were informed by its observed gaps. It is a development check, not fresh or confirmatory validation. Prior review findings and public review history are not delivered to the model calls.

## Changes and comparison

Reported-results workbooks become an immutable register of worksheet names, cell addresses, literal cached values, blank-cell semantics, and separate merged ranges. No values are recalculated and no labels are filled down. Source row IDs support exact quotations in evaluation and debate evidence. Manuscript comments still anchor to the original manuscript.

The investigator explicitly reconciles reported results across prose, captions, and matching table tests. It connects biological claims to collected and reported endpoints, then traces comparisons through design and experimental units. These are investigative checks, not required defects. Each check records the strongest author defense and remaining uncertainty.

Debate retains opposing arguments and complete issue and sentence-component accounting. Its instructions concentrate on source disputes, unsupported premises, proportional requests, and preserving distinct scientific questions. One fresh model session performs the debate, not independent human or model votes.

All generation conditions use question-only findings with empty replacement strings enforced in the schema and runtime validation. Both initial reviewers may preserve eight candidates and select five, with no more than 900 words across candidate comments. Debate selects at most five from the complete investigator candidate ledger. Complete cell values and the same prose, supplementary text, advisory Scaffold diagnostics, and three main figure pages are delivered to all conditions. No interactive source tools are used in this bounded retest. This tests a deterministic evidence packet and review protocol, not the value of tool access.

The single comparator receives one ordinary review call with the improved packet. PRA receives one structured investigator call and one debate call. Comparing the initial outputs holds model-call counts equal. Comparing the final PRA output to the single reviewer does not match total compute. A same-family anonymous evaluator assesses the single output, investigator selection, and debate selection. Randomized labels and the mapping are saved before inference. The evaluator receives no workflow identity, check records, debate records, or prior scores. Style can still reveal workflow, so blinding is incomplete in principle.

## Budget and stopping

Exactly one development manuscript and at most four Sol medium calls are authorized for this experiment: single review, investigator, debate, and evaluator. The launch stop is 450,000 observed tokens including cached input. A running call can cross that threshold. No automatic retries, model fallback, paid API calls, credit purchase, or usage reset are permitted. If execution or validation fails, preserve the failure and complete available offline analysis without adding a new model call.

## Assessment

Report findings and candidate coverage separately from selected-review quality. Record issues preserved, narrowed, resolved, or deferred by debate. Source-quote validation establishes reference identity, not scientific correctness. Failed ratings remain unscored. Keep justified ambiguities separate from demonstrated errors, and assess false premises and excessive requested work. Audit consequential disagreements against original sources without modifying frozen automated grades.

Report actual per-call input, cached input, output, and total observed usage. Previous trials used different source delivery and call counts, so between-trial cost and finding differences are descriptive. One known paper and one same-family judge cannot establish superiority, publication readiness, or human-review overlap.
