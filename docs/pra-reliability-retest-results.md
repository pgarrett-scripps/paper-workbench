# Ecology reliability retest

The repaired workflow completed both ecology reviews and their blind assessment. The model judge preferred PRA. All nine finding assessments passed source-reference validation. This is a repeat-paper development result with Terra, not an independent replication of the earlier Sol health comparison.

The judge preferred PRA because it framed the experimental-design questions conditionally, distinguished a community-level null result from a species-specific result, and added a proportionate question about the reporting of pointwise tests. These are model judgments, not confirmed scientific errors.

Both reviews questioned greenhouse replication, hive crossover and carryover, the link between field pollen composition and constructed diets, and larval allocation and attrition. PRA also requested the number of time-specific tests, their multiplicity handling, and the complete estimates and intervals.

The manuscript supports that additional question. Block `b0028` describes separate models at each time point after a significant interaction. Block `b0038` highlights the 6:00 results at P = 0.046 and P = 0.024. That supports a request for the testing and reporting details. It does not establish that the analyses were invalid.

The judge also identified an overstatement in the single review: alternate-day heating and alternating treatment between hives can be compatible. The useful concern is the unreported schedule and handling of residual effects. PRA's final wording made that distinction more carefully.

## What debate preserved

The investigator emitted five candidates, all of which remained in the final review. Its 13 declared candidate components were recorded as preserved. Three components from two discarded hypotheses were recorded as resolved. No candidate was lost to the five-finding presentation limit in this run.

The discarded hypotheses concerned figure timing and an allegedly undisclosed limitation of the pollen-return proxy. The final inventory kept both in the resolved category, rather than incorrectly presenting them as outstanding concerns.

This is structural retention plus coordinator inspection of the major topics. Exact quotations and component accounting do not mechanically establish complete semantic preservation. The blind judge compared the single review with the final PRA review. It did not independently compare the investigator against debate.

## Repairs exercised

The previously implemented finite manuscript-reference schema and advisory-coverage isolation were used in the live review. Both review conditions completed without invalid source handles. This run does not isolate which repair caused the reliability improvement.

The blind judge now selects immutable source handles too. Code expands the exact original quotation and source block. Support spanning two manuscript blocks remains two separate references. Image observations retain their own validated image identifiers. Unknown, mixed and raw text references are rejected.

All nine ratings passed the existing evidence auditor after that transformation. Source-reference validity remains separate from whether a scientific interpretation is correct.

The reviewer now accepts an explicit Sol or Terra model selection. Sol remains the default. Unsupported model names fail before generation, and the runtime does not automatically switch models.

## Limitations and cost

This was the same ecology manuscript used in the prior failed trial. Prior outputs informed the engineering repairs. It is a development retest, not a fresh or held-out paper.

Both review conditions and the blind judge were explicitly pinned to Terra at medium effort. The transport records the requested model, but its event stream does not independently expose the resolved model. The original health comparison used Sol, so these results should not be pooled into a single superiority estimate.

The conditions received the same initial manuscript, small scientific supplements, figure pages, precomputed guidance, frozen source packet and total tool budget. PRA used twice the generation calls and about 2.01 times the observed generation tokens. Neither completed review condition used an MCP tool call. This result therefore does not demonstrate value from live literature or domain database integrations.

Four completed model calls consumed 301,619 observed input and output tokens, including 80,208 for the blind judge. There were also two preserved failed launches: a local CLI initialization failure and a Sol capacity rejection. The capacity rejection supplied no usage receipt, so its usage is unknown and is not included in that total. No paid credits or resets were used. Rounded account-wide consumption moved from 36% to 37%, which is not a precise task attribution.

All 237 offline tests passed. The new judge schema was separately checked against valid handles, invented handles and unknown image identifiers. Frozen code, input hashes, raw model output, hydrated references, anonymous labels, usage receipts and the earlier failures remain available.

## Decision and next work

Keep the current candidate-preserving debate and the source-handle protections. This pass produced a complete comparison, retained the useful candidates and added one supported clarification. There is no reason to alter the review prompts merely to seek another win on this paper.

The next useful evaluation should freeze this workflow and test transfer to new manuscripts. It should measure consequential supported additions, unsupported premises, retained findings, delivery success and cost. A compute-matched single-agent comparison is needed before attributing gains to debate rather than the extra model pass.

For the domain integrations, use a paper containing a concrete claim that requires an external source, then compare access with no access under the same review workflow. Tool-call count alone is not a benefit, and mandatory browsing would increase cost without establishing value.

Independent expert spot checks remain necessary for a publication claim. One same-family blind model judge can guide development, but cannot establish that PRA is scientifically superior.
