# Four-condition development pilot

Four locally fresh published manuscripts, one each from molecular biology, ecology, experimental behavior and observational public health. Selection precedes review generation. This is a development pilot with one paper per domain, not a powered validation study or a historical peer-review reconstruction.

## Conditions and planned contrasts

| Condition | Input and method | Passes |
| --- | --- | --- |
| Basic one | Neutral scientific review guidance, full supplied manuscript text and three original figure pages, no tools | 1 |
| Basic two | Ordinary revision of the exact basic one draft using the same evidence | 2 |
| Workspace | Full workspace, domain guidance, diagnostics, result map and bounded tools. Ordinary revision of the shared investigator draft | 2 |
| PRA | The same investigator draft, followed by structured debate and recorded issue dispositions | 2 |

Basic two versus basic one tests an additional ordinary pass. Workspace versus basic two tests the workspace package, including structured guidance and evidence access. PRA versus workspace tests the second-stage debate procedure conditional on an identical investigator draft. PRA versus basic one estimates the complete package difference at different effort. These are matched pass counts, not equal realized token budgets.

All model calls request gpt-5.6-terra at medium effort. The CLI records the requested model but does not expose the resolved model in its event stream. Final scientific reviews have the same five-finding ceiling and approximately 900-word instruction. Exact source quotations are excluded from that word guidance. The initial workspace investigator may preserve up to ten candidate findings. Shared source handles, anchoring and edit guards are mechanical infrastructure in all arms. The basic arms receive no domain checklist, diagnostics, result map or external tools.

## Shared drafts and isolation

There are five new generation calls per paper. The first basic call serves both basic conditions. The two workspace arms share one investigator call, then receive different second-pass instructions. An immutable checkpoint captures the first draft, prior hypotheses, source cards, raw source cache and source request state before debate. Ordinary revision receives this checkpoint, never the debate output or its later evidence. Model sessions are fresh and isolated. Shared drafts create paired, dependent observations, which must not be counted as independent replications.

Workspace arms have four tool calls in the first pass and two in the second, with six total external requests per logical condition. The ordinary branch inherits the investigator's spent external allowance. Approved public retrieval is live and cached with provenance. No paid API, full analysis reruns, large data acquisition or human peer-review histories are allowed. Source availability is present day. No claim of reconstructing evidence available at original publication is made.

Full main text, references and small supplied supplements are common across conditions. Figure access starts with the same first three selected figure pages. Workspace tools may inspect additional original pages and supplied figure previews within the tool budget. Raw measurement datasets are excluded. Small scientific tables and variable dictionaries are preserved with provenance. The judge receives the union of inspected source images, up to ten, and eligible cited external evidence verified against raw cache hashes.

## Blinded evaluation

One fresh same-family model judge per paper receives four anonymous final reviews, full source text, verified cited evidence and source images. A predeclared balanced four-order schedule places every method in every label position once. All six pairwise preferences and an overall preference are collected in the same call. Tie and uncertain are valid outcomes. Pairwise judgments from the same call are dependent and do not multiply the sample size.

Primary descriptive outcomes are source-supported consequential concerns and clarifications, unsupported allegations, unverifiable findings, excessive requests, delivery failures, and actual usage. Preference is secondary. Every finding requires source-reference validation. Invalid ratings remain unscored without a retry. Audit validity establishes source identity and accounting, not scientific correctness. Preference remains provisional when relevant ratings fail validation.

Inspect before-and-after findings for lost, refined, added and rejected issues, including PRA's secondary inventory and dispositions. Main-review quality is judged on the common five-finding ceiling. Preserved secondary findings are a separate retention outcome, not extra judged main findings. Automated retention and quality judgments require later expert checking. Human-review overlap is not measured in this pilot.

## Budget and interpretation

At most 24 new calls: five generation calls and one judge call for each of four papers. No automatic retries, fallback models or paid credits. Stop launching calls after 1.8 million observed tokens or any unresolved usage. This is a launch threshold rather than a hard token cap on an in-flight call. Actual logical condition cost includes its shared initial pass. Incremental study usage counts that receipt only once.

Inputs, prompts, code and the label schedule are hashed before any generation. Failures and raw outputs remain in the record. No prompt tuning between papers. Any changes motivated by this pilot require a new version and new evaluation. These four papers remain development papers and must not silently become untouched confirmatory cases after tuning. The larger 24-paper study is not launched by this authorization.
